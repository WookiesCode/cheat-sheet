HEX CODE (0x80)
BOOT PHASE & SEVERITY PEI / MRC MEMORY FAULT (HALT)
0x55 — Memory Not Installed: No DDR4/DDR5 RDIMM detected in primary channels.

Rack Action: Verify DDR4/DDR5 RDIMMs are fully latched in the primary slots first. If populated, reseat DIMMs or test with 1 known-good DIMM in the first slot of the first CPU, and inspect CPU socket LGA pins for bent contacts or uneven heatsink torque.
